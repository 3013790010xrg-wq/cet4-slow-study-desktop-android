# 四级慢慢学 v1.1.0 · 电脑版和安卓版

适合从基础单词开始备考英语四级的个人学习工具。

## 下载与使用

- **电脑版**：下载 `cet4-slow-study-desktop-v1.1.0.zip`，完整解压，打开文件夹中的 `index.html`，用 Chrome 或 Edge 学习。它是免安装的本地学习页面。
- **安卓版**：下载 `cet4-slow-study-android-v1.1.0.apk`，在 Android 7.0 或更新系统上安装。系统询问时允许本次来源安装。已安装旧版的用户可直接覆盖安装，建议不要先卸载。
- `SHA256SUMS.txt` 提供下载文件的完整性校验值。请下载上面的 ZIP / APK；GitHub 自动生成的 Source code 压缩包只有本仓库说明。

## 本次更新

- 首页和冲刺计划倒计时按北京时间自动跨天更新。
- 本场考试结束后自动切换到下一场；未公布日期会标注“预计”。
- 保留词汇、阅读、听力、模拟卷，以及写作改错和练习估分。
- 两个安装包均包含 30 份历年试卷/解析 PDF 和 8 份听力 MP3，资料来源和说明见包内文档。

核心功能可离线使用；2026 年 6 月听力仍需从资料来源网页联网收听。系统英文朗读效果取决于设备已安装的语音。

学习进度只保存在本机；清除浏览器数据或卸载应用可能删除进度。写作评分是离线规则练习估分，不是官方成绩。安卓版使用与前版相同的测试签名，面向个人侧载安装。
